### 🤖 Featured Project: Call-Audit-AI
An automated quality-audit pipeline for call-center recordings.

**Pipeline:** audio → speech-to-text with speaker diarization → rules + LLM auditor → human-vs-AI comparison → web dashboard.

* **Two call types**, short outbound contacts and long sales calls (up to 65 min), each with its own evaluation logic.
* **Hybrid design:** simple rules resolve the easy cases without calling the LLM, and the LLM handles the rest. This cut cost and latency.
* **Evidence-based output:** every decision comes with a verbatim quote, a timestamp, a reason and a confidence level.
* **Validated against a human analyst**, with a per-item comparison to find where criteria differ.
* **Cost and time tracked per call:** about US$0.002 per short call and about US$0.26 per 19-minute call, with processing in seconds to minutes.
* **Built with:** Python, Deepgram, Claude (structured outputs and prompt caching), Streamlit.
